# Privacy Policy – Readable Text

_Last updated: November 2026_

Readable Text is a Chrome extension that improves how text is displayed on ZenHR (app.zenhr.com). It is an independent project and is not affiliated with or endorsed by ZenHR.

## Data collection

Readable Text does **not** collect, store, transmit, sell or share any personal data or user content.

- The extension only runs on pages at `https://app.zenhr.com/*`.
- It reads the text already shown on those pages solely to display it with line breaks, bold text and bullet lists.
- All processing happens locally in your browser. No text, page content or usage data is ever sent to the developer or to any third party.
- The extension makes no network requests, uses no analytics and contains no tracking.
- It does not use cookies or browser storage.

## Permissions

The extension requests access only to `https://app.zenhr.com/*`, which is needed to format text on those pages. It requests no other permissions.

## Changes

If this policy changes, the updated version will be published on this page with a new date.
