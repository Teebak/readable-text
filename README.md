# Readable Text

A Chrome extension that makes long text on ZenHR readable.

- Keeps line breaks
- `**bold**` shows as **bold**
- Lines starting with `- ` become bullet lists



# Privacy

Everything runs locally in your browser. Readable Text collects no data, makes no network requests and only runs on app.zenhr.com. See the privacy policy.
